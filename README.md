# Gridworks — Project Bible

`Gridworks`는 지역 전력회사를 운영하며 발전소, 송전망과 변전소를 직접
건설하고, 폭염과 설비 고장 속에서도 안전 기준을 지키며 총비용을 줄이는 싱글 플레이
전력망 건설·운영 전략 게임이다.

1.0은 공간 건설과 신뢰도 계획에 집중한 3장 핵심 캠페인과 고정 챌린지를 목표로 한다.
경제는 현금·전력 판매·발전비·정전 보상만 사용하고 프로젝트 금융은 후속으로 미룬다.
첫 milestone의 active 밸런스 파라미터는 3개뿐이며 이후에도 최대 6개로 제한한다.
구현 기준은 `Godot 4.7.1 .NET + C#`이며, 권위 시뮬레이션은 엔진에 의존하지 않는 순수
.NET 라이브러리로 분리한다.

1.0 이후의 우선 제품 방향은 일반 발전원 수집이 아니라 플레이어가 직접 입지·건설하는
원전과 데이터센터, 그리고 두 시설이 공유하는 단일 냉각수 제약이다. 수원지 최대거리 안의
데이터센터는 수랭·공랭을 전환할 수 있고, 물을 절약하면 계통 전력 피크가 커진다. 이 확장은
1.0 검증 전에는 구현하거나 기반을 선구축하지 않는다.

이 디렉터리는 게임을 이해하고 제작 방향을 결정하는 데 필요한 완결된 기획 패키지다.
외부 프로젝트 파일이나 별도 문서를 전제로 하지 않는다.

## 권위 순서

1. 코드가 생기기 전에는 `GAME_DESIGN_KO.md`의 규칙·표·산식이 숫자의 기준이다.
2. 첫 코드 커밋부터 `data/`의 versioned JSON/CSV와 schema가 catalog·scenario 숫자의 단일
   기계 권위이며, 문서 표와 UI 기준값은 여기에서 생성한다.
3. 제품 범위는 `SCOPE_1_0.md`와 `POST_1_0.md`의 경계를 따른다.
4. 화면 언어와 이미지 제작 조건은 `VISUAL_PRODUCTION_SPEC.md`가 기준이다.
5. PNG는 의도와 구도를 전달하는 시각 참고 자료이며, 글자나 숫자가 문서와 다르면 문서를
   따른다.

통화 단위 `M`, 전력 단위 `MW`, 에너지 단위 `MWh/GWh`, 시간 단위 `D-일수`는 모든 문서와
화면에서 같은 의미로 사용한다.
