# Gridworks — Project Bible

`Gridworks`는 지역 전력회사를 운영하며 발전소, 송전망과 변전소를 직접
건설하고, 폭염과 설비 고장 속에서도 최소 생애주기 비용으로 전력을 판매하는 싱글 플레이
전력망 건설·운영 전략 게임이다.

1.0은 공간 건설과 신뢰도 계획에 집중한 3장 핵심 캠페인과 고정 챌린지를 목표로 한다.
구현 기준은 `Godot 4.7.1 .NET + C#`이며, 권위 시뮬레이션은 엔진에 의존하지 않는 순수
.NET 라이브러리로 분리한다.

이 디렉터리는 게임을 이해하고 제작 방향을 결정하는 데 필요한 완결된 기획 패키지다.
외부 프로젝트 파일이나 별도 문서를 전제로 하지 않는다.

## 권위 순서

1. 게임 규칙과 숫자는 `GAME_DESIGN_KO.md`가 기준이다.
2. 화면 언어와 이미지 제작 조건은 `VISUAL_PRODUCTION_SPEC.md`가 기준이다.
3. PNG는 의도와 구도를 전달하는 시각 참고 자료이며, 글자나 숫자가 문서와 다르면 문서를
   따른다.

통화 단위 `M`, 전력 단위 `MW`, 에너지 단위 `MWh/GWh`, 시간 단위 `D-일수`는 모든 문서와
화면에서 같은 의미로 사용한다.
