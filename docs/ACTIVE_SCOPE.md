# 현재 작업 범위

## 상태

**활성 구현 scope가 없다.**

8장 cumulative route의 exact `LONGEST_NIGHT` standard result→city report→medical witness→closing이
완료됐다. 세 epilogue card는 strict base content를 읽고 completed Core outcome의 세 Keep/Defer 결과와
남은 자금을 표시한다. 성공하지 못한 마지막 장은 epilogue에 들어가지 않으며, finale부터 마지막 카드
close까지 Core canonical state는 바뀌지 않고 완료 망은 읽기 전용으로 남는다.

이 단계는 Debug/Release build, `./dev check`, 전체 Godot UI harness와 두 독립 review를 통과했다.
production-input 직접 플레이의 관찰 상한은 여전히 `NORTH_BANK_PROMISE`까지 4장이다. save/resume,
제품 title의 8장 진입, 완료 후 result/chapter/replay 선택, settings/audio, package와 공식 UX 평가는
완료되지 않았다.

다음 구현을 시작하려면 [남은 작업](NEXT_TASKS.md)에서 한 단계만 선택해 결과물, 수정 범위, 범위 밖
항목과 완료 검사를 이 문서에 먼저 적는다. backlog나 준비된 코드는 구현 권한이 아니다.
