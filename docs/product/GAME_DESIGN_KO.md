# Gridworks — 게임 기획서

> 한 줄 소개: **살아 움직이는 산업도시 위에 설명 가능하고 여유 있는 전력망을 건설하라.**

이 문서는 장기 제품 경험만 정의한다. 현재 구현 권한은 [현재 작업 범위](../ACTIVE_SCOPE.md), 단계
순서는 [남은 작업](../NEXT_TASKS.md), 시각 표현은 [비주얼 제작 명세](VISUAL_PRODUCTION_SPEC.md),
설비와 표현 coverage는 [오브젝트 카탈로그](OBJECT_CATALOG.md)가 소유한다.

## 1. 플레이어와 도시

플레이어는 청류시 전력운영센터의 책임자다. 해온강을 따라 주거지·의료원·정수장·산업단지가
성장했지만 전력망은 오래된 서부 전원과 몇 개의 공유 회랑에 의존한다. 플레이어는 기존 망을
운영하면서 새 전신주·선로·변전소를 건설해 병목과 단일 고장점을 줄인다.

도시는 추상 그래프가 아니다. 도로, 하천, 제방, 주거 밀집지와 산업 설비가 보이는 고정 사선
아이소메트릭 세계다. 설비를 어디에 놓고 어느 회랑을 공유하는지가 비용·공기·위험과 연결된다.

## 2. 핵심 약속

### 2.1 전기는 실제 망을 따라 흐른다

발전 접속점에서 수요처까지 완공되고 사용 가능한 경로가 이어져야 공급된다. 공간에서 두 선이
교차해도 같은 접속점이 아니면 연결되지 않는다. 발전량 총합이 충분해도 중간 선로·전신주 접속부·
변전소 주기기의 한도가 부족하면 공급되지 않는다.

### 2.2 공유는 싸지만 책임이 커진다

하나의 주간선에서 여러 수요로 분기하면 비용과 시간이 줄어든다. 대신 사용량과 사고 영향이 공유된다.
독립 회랑과 다른 발전 접속점을 쓰면 안전하지만 다음 공사에 쓸 자금·공간이 줄어든다.

### 2.3 시간은 계속 흐른다

공사는 주문 순간 완성되지 않는다. pause·1×·2×·4×로 시간이 흐르고, 공사 완공·사건 시작·열 노출
소진·보호정지·복귀가 정확한 시각에 일어난다. 중요한 사건은 수평 사건 지평선에 예고되고 필요할 때
자동 일시정지한다.

### 2.4 위기는 숨은 주사위가 아니다

폭염, 계획 사용불가와 위험구역 사건은 이름·시각·영향 대상을 가진다. 비상 한계를 사용할 수 있는
사건도 미리 알려 준다. 연속 한계를 넘은 설비는 허용시간 동안 비상 운전한 뒤 보호정지하고, 정해진
냉각 뒤 복귀한다.

### 2.5 기술 결과는 사람에게 닿는다

의료원 전력은 생명 유지, 정수장은 식수, 주거지는 폭염 대피, 산업단지는 도시 일자리와 연결된다.
결과는 성공/실패 점수보다 어떤 설비와 경로가 누구를 지켰는지 설명한다.

## 3. 핵심 루프

```text
도시와 사건 지평선을 읽는다
→ 현재 경로·열여유·첫 병목을 확인한다
→ 전신주·선로·변전소 초안을 배치한다
→ 비용·완공 시각·사건별 공급과 보호정지를 비교한다
→ 공사를 발주하고 시간을 운용한다
→ 완공·사건·비상·보호정지를 도시 위에서 관찰한다
→ 원인과 사람의 결과를 확인하고 망을 보강한다
```

즉시 보상은 새 선로가 완공되어 청록색 통전 흐름과 도시 불빛이 이어지는 순간이다. 장기 보상은
노후 방사형 망이 여러 전원·분기·우회 회랑을 가진 도시망으로 변하는 물리적 풍경이다.

## 4. 건설

- 보이는 격자 없이 고정소수점 세계 좌표에 배치한다.
- 전신주·변전소의 점유영역은 지도 밖, 수면, 건물과 다른 설비를 침범할 수 없다.
- 선로는 완공 접속점에서 시작해 허용 경간 안의 지지점을 거쳐 다른 접속점에서 끝난다.
- 강 위에 새 지지 설비를 세울 수 없지만 육지 endpoint 사이 가공선 횡단은 가능하다.
- 한 선로 공사의 모든 지지점과 구간은 함께 시운전되어야 공급 계산에 들어간다.
- 초안은 마지막 단계를 되돌리거나 두 번의 명시적 취소 입력으로 전체 취소한다.
- 발주 전에는 Core quote의 비용·공기·완공 시각·거부 원인을 보여 준다.
- 한 번에 한 공사만 진행하며 자동 경로·정답 전신주·범용 완공망 편집기는 제공하지 않는다.

## 5. 공급과 열

수요 하나는 한 발전원·한 단순 경로로 전량 공급되거나 미공급된다. 모든 후보를 결정론적으로
평가하고, 열 등급·비상 설비 수·최소 남은 한도·발전 순서·경로 순서로 하나를 고른다. 이미 선택된
수요의 공유 사용량을 누적하므로 뒤 수요는 남은 한도만 사용한다.

화면은 선택 수요에 다음을 연결해 보여 준다.

```text
수요와 현재 요구량
발전 접속점 → 전체 경로 → 수요
이름 붙은 첫 병목
현재 사용 / 연속 / 비상 / 남은 여유
비상 노출 남은 시간 또는 보호정지·복귀 시각
```

이 모델은 22.9 kV급 지역 배전망의 게임용 계획 추정이다. 전압강하·무효전력·주파수·상불평형·
상세 보호계전과 실제 안전 설계는 계산하지 않는다.

## 6. 화면 경험

기본 화면은 세 부분이 한 세계를 공유한다.

1. 상단 HUD: 현재 목표, 시각, 자금, 필수 공급, pause·속도
2. 중앙 world: `./assets` 방향의 촘촘한 아이소메트릭 도시와 실제 전력망
3. 하단 한 줄 사건 지평선: 사건·공사 완공·결정 기한·보호정지·복귀의 시간 관계

Inspector, build shelf와 action dock는 선택·도구·결정이 있을 때만 나타난다. 항상 열린 긴 오른쪽
패널로 지도를 줄이지 않는다. 이야기와 결과는 하나의 blocking modal만 사용한다.

## 7. 시각적 제품 정체성

Gridworks의 지도는 밝고 깨끗한 도시 builder도, 파란 선 위주의 엔지니어링 도식도 아니다.

- 오래 운영된 산업도시의 숯빛 지형, 콘크리트·강철·산화 표면
- 따뜻한 창·가로등과 차가운 통전 glow의 대비
- 작게 축소해도 class가 다른 전신주·변전소·시설 실루엣
- 정상 상태에서도 충분히 촘촘한 도로·필지·주거·산업 환경
- 폭염·비·야간이 같은 world의 광원·대기를 바꾸는 상태
- cyan 통전, amber 계획·공사, orange/red 위험·정지
- 색, 선/패턴, 아이콘/문장의 다중 상태 표현

정확한 기준과 금지 근사는 [비주얼 제작 명세](VISUAL_PRODUCTION_SPEC.md)가 소유한다.

## 8. 이야기와 캠페인

프롤로그는 기본 건설, 의료원 두 접속과 범람 시험, 남부 전원 접속과 연속 한계를 익히게 한다.
본편은 북안 성장, 공유 구간과 비상 열여유, 범람 전 공사, 계획정지, 최대수요와 가장 긴 밤으로
이어진다. 같은 도시·망·자금이 남아 이전 선택이 다음 사건의 풍경과 결과가 된다.

반복 인물은 운영센터장, 계통운영관, 의료원 시설책임자와 재난대응관 네 명이다. 대화 선택지·호감도·
긴 컷신·음성은 만들지 않는다. 브리핑, 핵심 사건과 결과만 짧게 쓴다.

이 문서는 8장 목표 경험만 소유한다. 현재 native 구현·직접 관찰 범위는 [루트 README](../../README.md),
아직 구현하지 않은 순서와 완료 조건은 [남은 작업](../NEXT_TASKS.md)에서만 갱신한다.

## 9. 문체와 접근성

- 문장은 `현재 상황 → 영향/이유 → 다음 행동` 순서로 쓴다.
- 버튼은 `전신주 놓기`, `선로 잇기`, `공사 발주`처럼 대상과 행동을 함께 쓴다.
- 기계 ID, enum, raw exception과 구현 단계 이름을 플레이어에게 보이지 않는다.
- 돈·전력·시각은 `370만 원`, `2.5 MW`, `2일차 06:45`처럼 의미와 단위를 붙인다.
- mouse와 keyboard를 동등하게 지원하고 focus·pause reason을 복원한다.
- 색만으로 연결·건설·비상·정지를 구분하지 않는다.
- motion reduction에서 필수 정보와 상태 구분이 사라지지 않는다.

## 10. 1.0에서 제외

- full 3D·자유 회전 camera·procedural city·sandbox
- AC 전력조류·상세 보호계전·실시간 수동 급전
- 발전 기술 tree·전력시장·대출·자재·차량·여러 공사반
- 완공 설비의 부분 철거·범용 노선 편집기
- 대화 선택지·호감도·긴 cinematic·voice-over
- mobile·gamepad·multiplayer·live service 동시 개발
- reference 화면·다른 게임 자산의 복제

이 기능이 없어서 현재 핵심 선택이 성립하지 않는다는 재현 가능한 관찰이 생길 때만 별도 계약으로
검토한다.
