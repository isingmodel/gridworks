# Gridworks — 오브젝트 카탈로그

이 문서는 플레이어가 보는 오브젝트의 의미와 출시판에서 가능한 동작을 정리한다. 정확한 수치와
식별자는 [출시판 데이터](../scopes/RELEASE_REBUILD.md#9-데이터와-코드-경계), 현재 구현 권한은 루트
[README](../../README.md)가 소유한다.

## 상태 표기

- `구현됨(내부 RC)`: 현재 기본 장면과 내부 출시 후보에서 사용할 수 있는 기능
- `회귀 전용`: 과거 검증 장면에만 남아 있고 출시판 능력으로 세지 않는 기능
- `제외`: 1.0에서 만들지 않는 기능

## 현재 경계

기존 내부 후보에는 고정 출발점·도착점 사이의 순서 있는 선로, 한 변전소, 병원 주·예비회선,
가스발전소 한 기, 공장과 한 폭염 사건이 있다. 전신주는 선로 안의 경유점이라 분기·합류할 수
없다. 이 경로는 회귀로 보존하지만 출시판 오브젝트 능력의 권위가 아니다.

출시판은 접속점과 선로 구간으로 된 명시적 그래프를 새로 만든다. 한 번의 선로 공사는 단순한 한
경로지만, 완공된 전신주·변전소를 다음 공사의 시작점이나 끝점으로 다시 사용해 망 전체에서
분기와 합류를 만든다.

## 전력회사 설비

| 오브젝트 | 상태 | 플레이어 동작 | 출시판 규칙 | 제외 |
|---|---|---|---|---|
| 발전 접속점 | 구현됨(내부 RC) | 선로를 연결하고 공급 상태 확인 | 출력 정격, 운전 순서, 사용량 | 발전기 세부 운전·연료조달 |
| 일반 전신주 | 구현됨(내부 RC) | 선로 공사 중 위치 지정, 완공 뒤 새 분기 시작 | 최대 3개 선로 구간, 통과 정격, 현재 사용량 | 장력·풍하중·재고 |
| 보강 전신주 | 구현됨(내부 RC) | 큰 분기·합류 지점에 선택 | 최대 4개 선로 구간, 더 큰 통과 정격과 비용 | 사용자 지정 하드웨어 |
| 일반 배전선 | 구현됨(내부 RC) | 두 접속점 사이 경로 계획·발주 | 거리 한도, 공급 정격, 현재 사용량, 공간 위험 | 도체 세부 사양·상불평형 |
| 보강 배전선 | 구현됨(내부 RC) | 공유 주간선·우회선에 선택 | 더 큰 정격과 비용 | 연속 열·비상정격 |
| 소형 배전 변전소 | 구현됨(내부 RC) | 강물이 아닌 빈 격자에 계획·발주, 선로 연결 | 접속 수, 변압 정격, 현재 공급, 연결 가능 구역 | 탭·무효전력·보호계전 |
| 대형 배전 변전소 | 구현됨(내부 RC) | 병원·산업지대 결절에 선택 | 더 많은 접속, 큰 정격과 비용 | 베이 상세 설계·증설 공사 |
| 선로 공사 | 구현됨(내부 RC) | 완공 접속점에서 시작, 전신주를 놓고 다른 접속점에서 종료 | 하나의 순서 있는 경로, 전체 원자 시운전 | 한 공사 안의 나무형 편집 |

### 연결 수와 정격

`연결 3/4`는 물리적으로 더 연결할 수 있는 선로 구간 수다. `사용 2.0 / 정격 2.5 MW`는 현재
공급 계산에서 해당 설비를 통과하는 전력과 한도다. 둘은 서로 다른 값이며 UI도 따로 보여준다.

전신주의 통과 정격은 실제 기계적 압력이나 도체 장력을 뜻하지 않는다. 고정 전압·역률을 가정한
분기점 설비와 도체 조합의 계획상 공급 한도다.

## 수요처와 비전력회사 설비

| 오브젝트 | 상태 | 의미 | 공급·사건 규칙 |
|---|---|---|---|
| 주거지 | 구현됨(내부 RC) | 일반 주거·상업 수요 | 장마다 작성된 수요, 미공급 시 임무 목표 실패 가능 |
| 청류의료원 | 구현됨(내부 RC) | 가장 높은 우선순위의 생명 유지 전력 | 주·예비 경로와 공간 사고 뒤 공급 판정 |
| 정수장 | 구현됨(내부 RC) | 도시 필수 서비스 | 미공급 시 해당 장의 필수 목표 실패 가능 |
| 산업단지 | 구현됨(내부 RC) | 큰 산업 수요 | 공유 주간선·분기점·변전소 병목을 만든다 |

현재 출시판의 병원은 생명 유지 전력 한 묶음만 사용한다. 각 수요 묶음은 한 경로로 전량
공급되거나 미공급된다. 병원 일반 부하, 내부전원과 별도 물류단지는 1.0에 넣지 않는다.

## 공간 레이어

| 레이어 | 상태 | 역할 |
|---|---|---|
| 건설 가능 지역 | 구현됨(내부 RC) | 막힌 칸을 제외한 격자에 전신주·변전소 배치 |
| 강 | 구현됨(내부 RC) | 내부·경계의 신규 변전소·중간 전신주 배치 금지; 고정 교량·보호기초 접속점과 선로 횡단은 허용 |
| 도로 | 구현됨(내부 RC) | 지도 정체성과 공간 선택의 시각적 맥락; 별도 건설 제한·비용 없음 |
| 서비스 연결 가능 구역 | 구현됨(내부 RC) | 변전소가 주거·산업 수요를 연결할 수 있는 기하학적 범위 |
| 위험구역 | 구현됨(내부 RC) | 닿은 여러 선로·설비를 한 사건에서 함께 제외 |

서비스 연결 가능 구역은 발전원이 아니다. 범위 안에 있어도 변전소가 상위망과 연결되지 않았거나
용량이 부족하면 공급되지 않는다.

## 건설 생명주기

```text
계획
→ 지형·위치·거리·접속 수·충돌 검토
→ 비용·공사기간 확인
→ 발주와 비용 지급
→ 공사 중
→ 전체 경로 시운전
→ 완공 망 편입
```

- 독립 설비 계획은 발주 전에 취소할 수 있다. 선로는 마지막 전신주를 되돌리거나 현재 경로 계획
  전체를 취소하며 중간 구간만 삭제하지 않는다.
- 공사 중 전신주와 선로 구간은 전력을 전달하지 않는다.
- 한 선로 공사의 모든 구간이 함께 완공되며 부분 통전은 없다.
- 공사 중 끝 접속점의 연결 자리는 예약되어 같은 자리를 중복 발주할 수 없다.
- 완공 자산의 부분 편집·철거는 1.0에서 제외한다. 장 재시작으로 복구한다.

## 연결과 공급 불변식

- 모든 선로 구간은 정확히 두 접속점 ID를 가진다.
- 접속점은 자기 형식의 최대 연결 수를 넘지 않는다.
- 선이 공간에서 교차해도 같은 접속점 ID가 아니면 연결되지 않는다.
- 같은 접속점 위치에 서로 다른 설비를 둘 수 없다.
- 플레이어가 새로 만드는 변전소와 중간 전신주는 강물 polygon의 내부·경계에 놓이지 않는다.
- 선로 구간의 강 횡단과 고정 교량·보호기초 접속점 사용은 허용한다.
- 공유 선로, 전신주와 변전소의 사용량은 배정된 모든 수요의 합이다.
- 발전원·선로·전신주·변전소의 실제 사용량은 정격을 넘지 않는다.
- 서비스 구역 부하는 선택한 변전소를 경로 끝으로 삼아 그 변압기 용량을 한 번 사용한다.
- 사건이 설비를 제외하면 같은 공급 계산을 처음부터 다시 수행한다.
- 닫힌 위험구역은 내부·경계 node와 교차한 개별 선로 구간만 제외한다.
- 동일한 데이터와 명령은 동일한 경로·사용량·첫 실패 원인을 만든다.

## 사건과 결과

| 사건 | 출시 역할 | 표현 |
|---|---|---|
| 설비 하나 사용불가 | 전기적 우회 검증 | 제거 설비, 남은 경로, 공급 변화 |
| 범람·회랑 사고 | 공간적으로 함께 노출된 설비 검증 | 위험구역, 함께 끊긴 선로, 필수서비스 결과 |
| 계획정지 | 다른 발전 접속점과 합류망 검증 | 정지 예고, 살아 있는 공급력과 병목 |
| 폭염 | 장에 고정된 최대수요와 지정 설비 사용 불가 | 사건 알림, 제외 설비·위험구역과 필수 공급 결과 |

확률 고장, 상세 수리, 실시간 수동 절체와 유상 수요감축은 1.0에서 제외한다.

## 출시판에 넣지 않는 오브젝트

배터리, 원전, 석탄발전, 데이터센터, 전력시장, 대출, 다중 공사반, 사용자 switch, 부분 선로 편집과
철거는 현재 출시판에 넣지 않는다. 새 오브젝트가 실제 관찰된 문제를 해결해야 할 때만 로드맵과
이 카탈로그를 함께 수정한다.
