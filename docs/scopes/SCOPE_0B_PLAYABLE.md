# Scope 0B 역사 안내

**상태: 완료된 역사 scope이며 현재 구현 권위가 아니다.**

이 경로는 동결된 [Scope 0B facilitator sheet](../../playtests/scope-0b/FACILITATOR_SHEET.md)의 역사 링크가
현재 문서 트리에서 잘못된 실행 지시처럼 끊기지 않도록 남긴 tombstone이다. Scope 0B가 속한 넓은
제품 이력은 [완료 이력](../archive/COMPLETED_HISTORY.md), 보존 파일의 현재 사용 경계는
[playtest 안내](../../playtests/scope-0b/README.md)가 설명한다.

당시 상세 scope 원문이 꼭 필요하면 Git commit `9aceaf7`의
`docs/scopes/SCOPE_0B_PLAYABLE.md`를 읽는다. 그 원문, 오래된 절대 경로와 실행 명령은 current R2 작업을
허가하지 않으며 현재 검사나 playtest에 사용하지 않는다.
