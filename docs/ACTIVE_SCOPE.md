# 현재 작업 범위

## 상태

**활성 구현 scope가 없다.**

`LONGEST_NIGHT`까지 작성된 8장의 누적 native wiring과 결정론적 검사가 완료됐다. 추가로 연결할
authored native 장은 없고, production-input 직접 플레이의 관찰 상한은 여전히
`NORTH_BANK_PROMISE`까지 4장이다. native route의 `CampaignComplete=true`는 8장 운행 종료이며
finale·epilogue, save/resume 또는 전체 제품 여정의 완료를 뜻하지 않는다.

다음 구현을 시작하려면 [남은 작업](NEXT_TASKS.md)에서 한 단계만 선택해 이 문서에 결과물, 수정 범위,
범위 밖 항목과 완료 검사를 먼저 적는다. backlog, 준비된 데이터나 이전 scope는 구현 권한이 아니다.
